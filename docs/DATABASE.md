# مستندات ساختار پایگاه‌داده (Database Schema Documentation)

این مستند تشریح کامل ساختار ۱۴ جدول موجود در پایگاه‌داده PostgreSQL پروژه **AuraVibe** است که بر اساس مایگریشن‌های واقعی موجود در مسیر `supabase/migrations/` تدوین شده است.

---

## فهرست جداول (Tables Overview)

| # | نام جدول (Table Name) | کلید اصلی (PK) | دسترسی خواندن عمومی (Public Read) | دسترسی مدیریتی (Admin Only) | هدف و شرح کاربرد |
|---|------------------------|----------------|-----------------------------------|-----------------------------|------------------|
| ۱ | `categories` | `id` (BIGINT Identity) | ✅ بله | مدیریت فقط ادمین | دسته‌بندی‌های کاتالوگ فروشگاه |
| ۲ | `product_badges` | `id` (BIGINT Identity) | ✅ بله | مدیریت فقط ادمین | برچسب‌های شاخص محصولات (جدیدترین، پرفروش‌ترین و...) |
| ۳ | `products` | `id` (BIGINT) | 🔍 فقط کالاهای فعال (`status = 'active'`) | مدیریت فقط ادمین | اطلاعات کامل محصولات و کاتالوگ |
| ۴ | `banners` | `id` (BIGINT) | 🔍 فقط بنرهای فعال (`active = true`) | مدیریت فقط ادمین | اسلایدرها و بنرهای تبلیغاتی دسته‌بندی‌ها |
| ۵ | `users` | `id` (BIGINT) | ❌ خیر (فقط مالک کاربر با auth یا ادمین) | ادمین دسترسی کامل | مشخصات مشتریان فروشگاه و آدرس‌ها |
| ۶ | `admin_users` | `id` (BIGINT) | ❌ خیر (فقط ادمین‌های فعال) | تغییر فقط Super Admin | مدیران سامانه، کد پرسنلی و سطوح دسترسی RBAC |
| ۷ | `orders` | `id` (TEXT) | ❌ خیر (فقط خریدار مربوطه یا ادمین) | ویرایش و حذف فقط ادمین | سفارش‌های ثبت‌شده مشتریان و ریز اقلام سبد |
| ۸ | `support_tickets` | `id` (TEXT) | ❌ خیر (فقط صاحب تیکت یا ادمین) | حذف فقط ادمین | گفت‌وگوها و تیکت‌های پشتیبانی آنلاین |
| ۹ | `articles` | `id` (BIGINT) | 🔍 فقط مقالات منتشرشده (`status = 'published'`) | مدیریت فقط ادمین | مقالات مجله مد و استایل آورا |
| ۱۰ | `global_seo` | `id` (INTEGER, singleton=1) | ✅ بله | ویرایش فقط ادمین | تنظیمات عمومی سئو، متاتگ‌ها و robots.txt |
| ۱۱ | `general_settings` | `id` (INTEGER, singleton=1) | ✅ بله | ویرایش فقط ادمین | تنظیمات هویت بصری، تماس، زمان کاری و نوتیفیکیشن‌ها |
| ۱۲ | `redirects` | `id` (TEXT) | ✅ بله | مدیریت فقط ادمین | قوانین ریدایرکت آدرس‌های قدیمی (301) |
| ۱۳ | `notifications` | `id` (TEXT) | ❌ خیر (تفکیک بر اساس نقش یا کاربر) | ثبت فقط ادمین | پیام‌ها و هشدارهای درون‌برنامه‌ای |
| ۱۴ | `audit_logs` | `id` (TEXT) | ❌ خیر (فقط ادمین احراز هویت‌شده) | ثبت و مشاهده فقط ادمین | سوابق عملیات مدیریتی و ممیزی سیستم |

## ۱. جدول `categories` (دسته‌بندی‌های محصولات)

* **هدف:** نگهداری دسته‌بندی‌های کاتالوگ فروشگاه (مانند ساعت، گردنبند، اسکرانچی و ...).
* **کلید اصلی:** `id` (`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`).
* **روابط:** توسط نام دسته‌بندی با ستون `category` در جدول `products` و `target_category` در جدول `banners` ارتباط معنایی دارد.

### ساختار فیلدها:
| ستون | نوع داده | پیش‌فرض / توضیحات |
|---|---|---|
| `id` | `BIGINT` | شناسه یکتا عددی خودکار |
| `name` | `TEXT NOT NULL` | نام دسته‌بندی به فارسی |
| `image` | `TEXT NOT NULL` | آدرس تصویر (SVG Data URL یا لینک باکت Storage) |
| `display_order` | `INTEGER NOT NULL DEFAULT 0` | اولویت نمایش در لیست‌ها |
| `created_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | زمان ایجاد |
| `updated_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | زمان آخرین ویرایش |

---

## ۲. جدول `product_badges` (برچسب‌های محصولات)

* **هدف:** مدیریت نشان‌ها و برچسب‌های تبلیغاتی روی کارت محصول.
* **کلید اصلی:** `id` (`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`).

### ساختار فیلدها:

| `id` | `BIGINT` | شناسه یکتای نشان |
| `title` | `TEXT NOT NULL` | متن برچسب (مثلاً 'جدیدترین‌ها'، 'تخفیف ویژه') |
| `color` | `TEXT` | کد رنگ اختیاری یا نام کلاس تم |
| `created_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | زمان ایجاد |
| `updated_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | زمان آخرین ویرایش |

## ۳. جدول `products` (کاتالوگ محصولات)

* **هدف:** ذخیره کامل اطلاعات و متادیتای محصولات فروشگاه.
* **کلید اصلی:** `id` (`BIGINT PRIMARY KEY`).
* **اینکس‌ها:** `idx_products_category`, `idx_products_badge`, `idx_products_status`.

### ساختار فیلدها:
| ستون | نوع داده | پیش‌فرض / توضیحات |
|---|---|---|
| `id` | `BIGINT` | شناسه محصول |
| `product_code` | `TEXT NOT NULL UNIQUE` | کد تجاری یکتا (مثال: `AUR-101`) |
| `name` | `TEXT NOT NULL` | نام عنوان محصول |
| `category` | `TEXT NOT NULL` | نام دسته‌بندی مرجع |
| `price` | `NUMERIC NOT NULL` | قیمت فروش جاری به تومان |
| `old_price` | `NUMERIC` | قیمت قبلی قبل از تخفیف (در صورت وجود) |
| `stock` | `INTEGER NOT NULL DEFAULT 0` | موجودی فیزیکی انبار |
| `images` | `JSONB NOT NULL DEFAULT '[]'` | آرایه‌ای از آدرس تصاویر گالری محصول |
| `main_image_index` | `INTEGER NOT NULL DEFAULT 0` | اندیس تصویر اصلی کاور |
| `video_url` | `TEXT` | آدرس ویدیو معرفی محصول (اختیاری) |
| `crop_data` | `JSONB` | مختصات برش تصویر `{x, y, width, height, aspectRatio}` |
| `badge` | `TEXT` | برچسب انتخابی محصول |
| `colors` | `JSONB NOT NULL DEFAULT '[]'` | آرایه کدهای رنگ هگز (مثلاً `["#37192C", "#FFF3C5"]`) |
| `description` | `TEXT NOT NULL DEFAULT ''` | توضیحات تفصیلی مشخصات محصول |
| `seo` | `JSONB DEFAULT '{}'` | متادیتا اختصاصی سئو محصول |
| `related_ids` | `JSONB DEFAULT '[]'` | آرایه شناسه‌های محصولات مرتبط |
| `status` | `TEXT NOT NULL DEFAULT 'active'` | وضعیت انتشار: `'active'`, `'draft'`, `'archived'` |
| `created_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | زمان ایجاد |
| `updated_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | زمان آخرین ویرایش |

| `phone` | `TEXT NOT NULL` | شماره تلفن همراه خریدار |
| `email` | `TEXT` | آدرس ایمیل |
| `avatar` | `TEXT` | آدرس تصویر پروفایل کاربر |
| `address` | `TEXT` | نشانی پستی دقیق |

| `status` | `TEXT NOT NULL DEFAULT 'active'` | وضعیت حساب: `'active'` یا مسدود |
| `block_reason` | `TEXT` | علت مسدودسازی در صورت تعلیق حساب |

## ۶. جدول `admin_users` (مدیران و دسترسی‌های RBAC)

| ستون | نوع داده | پیش‌فرض / توضیحات |

| `id` | `BIGINT` | شناسه داخلی مدیر در برنامه |

| `first_name` | `TEXT NOT NULL` | نام مدیر |
| `last_name` | `TEXT NOT NULL` | نام خانوادگی |
| `username` | `TEXT NOT NULL UNIQUE` | نام کاربری یکتا جهت ورود |

## ۷. جدول `orders` (سفارشات فروشگاه)

* **هدف:** ثبت و رهگیری کامل سفارشات خریداران، وضعیت فاکتور و سوابق تغییر وضعیت.
* **کلید اصلی:** `id` (`TEXT PRIMARY KEY` - مانند `ORD-10452`).
* **روابط خارجی:** `user_id BIGINT REFERENCES public.users(id) ON DELETE SET NULL`.
* **اینکس‌ها:** `idx_orders_user_id`.

### ساختار فیلدها:
| ستون | نوع داده | پیش‌فرض / توضیحات |
|---|---|---|
| `id` | `TEXT` | شناسه سفارش (هم‌ارز با `order_number`) |
| `order_number` | `TEXT NOT NULL UNIQUE` | شماره پیگیری سفارش |
| `user_id` | `BIGINT` | شناسه کاربر ثبت‌کننده در صورت لاگین |
| `customer` | `JSONB NOT NULL` | اسنپ‌شات مشخصات و نشانی خریدار در لحظه خرید |
| `items` | `JSONB NOT NULL` | آرایه اقلام سبد خرید شامل نام، کد، قیمت و تعداد |
| `subtotal` | `NUMERIC NOT NULL` | جمع کل ناخالص اقلام به تومان |
| `discount` | `NUMERIC NOT NULL DEFAULT 0` | مجموع تخفیف‌های اعمال‌شده |
| `total_amount` | `NUMERIC NOT NULL` | مبلغ نهایی پرداختی فاکتور |
| `shipping_method`| `JSONB NOT NULL` | جزئیات روش حمل انتخابی (پست، تیپاکس، آورا اکسپرس) |
| `order_status` | `TEXT NOT NULL DEFAULT 'جدید'` | وضعیت جاری سفارش در چرخه انبار |
| `payment_status`| `TEXT NOT NULL DEFAULT 'پرداخت شده'`| وضعیت تراکنش مالی |
| `tracking_code` | `TEXT` | کد رهگیری پستی مرسوله |
| `timeline` | `JSONB NOT NULL DEFAULT '[]'` | تاریخچه مراحل طی‌شده سفارش |
| `created_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | زمان ثبت سفارش |
| `updated_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | زمان آخرین تغییر وضعیت |
